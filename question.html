What is more expensive?

Four ways of using a language model, each drawn as the requests it sends. Decide which one costs most, then show the bills.

One request, as tall as the text the model reads for it A message you type Read from the cache New input Output

AOne question about a long document

“Read this 200-page report and tell me in which year the pilot study started.”

BA conversation during one day

50 short messages between morning and evening, each answered in a paragraph or two.

CA conversation over a month

The same kind of messages and answers, but only 25 of them, spread over 30 days.

DOne prompt to investigate a bug

“The login test has been failing since yesterday. Find out why.”

The bill does not follow the number of messages you type. It follows how many requests are sent, how much text each one carries, and whether that text is still in the cache.

The answers are too short to see in the bars above, a few hundred tokens in each request, but an output token costs times as much as an input token.
